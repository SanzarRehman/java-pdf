Testing Instructions

How to Test Custom Fonts

  1. Download fonts from Google Fonts or other sources (see fonts/README.md)
  2. When making the API request, include font files as assets:
    curl -X POST http://localhost:8081/api/v1.0/print \
    -F 'htmlFile=@3-custom-fonts.html' \
    -F 'assets=@fonts/Roboto-Regular.ttf' \
    -F 'assets=@fonts/Roboto-Bold.ttf' \
    -F 'assets=@fonts/OpenSans-Regular.ttf' \
    -F 'jsEnable=false' \
    --output custom-fonts-test.pdf
  3. The CSS processor will sanitize font references while preserving font-family declarations
  4. Font files will be available in the temporary directory for PDF generation
