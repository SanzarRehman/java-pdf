Chapter 3: Implementation Details

3.1 API Usage

To test headers and footers, create separate HTML files for header and footer content, then include them in your API request:

curl -X POST http://localhost:8081/api/v1.0/print \
  -F 'htmlFile=@4-header-footer.html' \
  -F 'headerFile=@header.html' \
  -F 'footerFile=@footer.html' \
  -F 'jsEnable=false' \
  --output header-footer-test.pdf
