Image and Logo Testing Overview

This document demonstrates various image and logo placement scenarios in PDF generation. It includes placeholders for different types of visual content that would typically be included in business documents.

Testing Instructions

To test with actual images, place image files in the test-scenarios/images/ directory and upload them as assets when making the API request:

curl -X POST http://localhost:8081/api/v1.0/print \ -F 'htmlFile=@5-images-logo.html' \ -F 'assets=@images/logo.png' \ -F 'assets=@images/chart.jpg' \ -F 'assets=@images/product.png' \ -F 'jsEnable=false' \ --output images-test.pdf

Note: The CSS processor will remove any background-image: url() references to prevent FileNotFoundException. Images should be embedded directly in HTML or handled through the assets system.
